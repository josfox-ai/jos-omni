# JOS Omni — public distribution documentation

JOS Omni documents platform-specific JOSFOX distributions and their availability. This repository is a public documentation hub; it does not contain the complete implementation monorepo.

## Start here

1. Read the [.jos specification](https://github.com/josfox-jos/jos-spec).
2. Select a target below and check its state and available download.
3. Follow only installation steps for published artifacts. Development targets without downloads are explicitly marked unavailable.

## Current verified distribution

[JOSFOX – JOS Open Standard 2.1.0 on VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=JOSFOX.josfox-jos) has a reachable VSIX, downloaded and hashed on 2026-11-05. This observation does not certify an editor session or compatibility with editor forks. Open VSX returned 404 for the queried `JOSFOX/josfox-jos` identity.

## Development coverage

31 Omni platforms are reported by the product catalog. A build and hello test were reported for the other 30; original receipts and real-host sessions have not been independently verified in this documentation revision. JosHubMac is an additional alpha-development application, outside that count. A documentation channel such as Stack Overflow is not a binary plugin.

Shared plugin definitions do not prove identical policy enforcement on every host. Every target must document actual capabilities, limitations, source/artifact version, test evidence and distribution links before claiming availability.

## Support and contribution

Use this repository's issues to report documentation or distribution-link problems. Never attach credentials. Implementation source, licensing and security reporting information will be added when bound to a release; no source license or store approval is implied by this documentation.
